# 🚀 KU-Emotion - MVP Version

Tələbə qeydiyyat və giriş (Authentication) sisteminin ilkin MVP versiyası. Bu layihə frontend və backend arxitekturasının sinxron işləməsini nümayiş etdirir.

## 📂 Layihənin Strukturu
* `/backend` - Flask (Python) ilə yazılmış API servisi.
* `/frontend` - HTML, CSS və Vanilla JavaScript ilə yığılmış istifadəçi interfeysi.
